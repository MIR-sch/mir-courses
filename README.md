# МИР — Курсы ОГЭ (PWA для Яндекс Диска)

Устанавливаемое на телефон веб-приложение (PWA) для онлайн-курсов подготовки к ОГЭ
по математике и информатике. Все данные хранятся на Яндекс Диске, вход — через Яндекс OAuth.

## Состав
- index.html, css/styles.css, js/app.js — приложение
- manifest.webmanifest, sw.js — установка на телефон и офлайн-кэш
- logo.png, icons/ — логотип «МИР» и иконки приложения

## Важно про Client Secret
Вы прислали Client Secret в переписке — он считается скомпрометированным.
**Перевыпустите его в Яндекс OAuth** (oauth.yandex.ru → ваше приложение → новый секрет).
Для работы приложения секрет не нужен: в браузере используется только Client ID,
а секрет нужен только серверным приложениям.

## Как развернуть (10 минут)
1. Загрузите папку `app` на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel — бесплатно).
   На GitHub Pages: создайте репозиторий, загрузите файлы, Settings → Pages → включите.
2. В Яндекс OAuth (https://oauth.yandex.ru) в настройках вашего приложения добавьте
   Redirect URI: `https://ВАШ-АДРЕС-САЙТА/` (например `https://username.github.io/repo/`)
   и поставьте галочку «Веб-сервисы» + доступ «Яндекс Диск: полный» (или «чтение и запись папки приложения»).
3. Откройте сайт с телефона → «Учитель» → «Войти через Яндекс» → войдите под аккаунтом
   учебного центра. Приложение создаст папку `/Приложения/МИР-Курсы` на Диске.
4. Добавьте учеников (каждому выдаётся код), загрузите видеоуроки, тесты, задания, настройки логотипа.
5. Нажмите «Публикация» → «Опубликовать/обновить» → появится **ссылка-приглашение**.
   Отправьте её ученикам и родителям: они открывают её, вводят свой код — и попадают в личный кабинет.
6. Установить на телефон: в Chrome (Android) — меню → «Установить приложение»;
   в Safari (iPhone) — «Поделиться» → «На экран «Домой»».

## Что уже работает
- Учитель: курсы (добавление новых помимо математики и информатики), видеоуроки, тесты,
  задания, оценки, посещаемость, оплаты с чеками, логотип центра, публикация.
- Ученик: уроки с видео и материалами, прохождение тестов, задания,
  оценки, расписание, посещаемость, чеки об оплате.
- Родитель: тот же кабинет + кнопка включения уведомлений об оценках.
- Уведомления: при входе показывается «Новая оценка…»; при разрешённом Notification API
  приходит системное уведомление.

## Честные ограничения (и как их закрыть)
1. **Полная защита видео от скачивания невозможна в принципе** — любой видео-поток,
   который играет на устройстве, можно записать. Меры уже включены: нет кнопки «скачать»,
   заблокировано контекстное меню, плеер без меню загрузки. Чтобы ссылка не гуляла —
   следующий шаг: короткоживущие подписанные ссылки через сервер (см. п. 3).
2. **Сдача работ от ученика к учителю**: без промежуточного сервера ученик не может
   писать в Диск учителя. Решения: (а) вставить ссылку Яндекс Формы в Настройках —
   ученики сдают решения туда, результаты видит учитель; (б) добавить серверный прокси
   (например, Яндекс Cloud Function) — могу написать его следующим шагом.
3. **Push-уведомления родителю** в фоновом режиме требуют сервер (Web Push + VAPID).
   Сейчас: уведомление при открытии приложения + баннер. Добавим сервер — будет полный push.
4. Ссылка-приглашение открывает общий каталог уроков — она не содержит личных данных;
   личные данные лежат в файлах с ключами-кодами вида `MK-XXXX`.
